# Rove — Value & Ownership Semantics Matrix (rust Target)

## 1. The Core Semantic Principle

`rust` consumes canonical verified typed HIR v1. The former direct-AST emitter
is not part of the active compiler path.

Rove is a **Value-Semantic by default** language with deterministic scoping:
1. **Assignment (`var b = a`)** represents a logical value duplication (copy / clone). Mutating `b` never alters `a`.
2. **Function Calls (`f(x)`)** pass by value logically. Calling `f(x)` does not invalidate or consume `x` in the caller's scope.
3. **Explicit Pointer & Aliasing** is exclusively permitted inside `unsafe { ... }` via raw addresses (`addr(x)`, `peek(p)`).

Hosted backends also share one Unicode contract: string `len()`, indexing, and
iteration operate on Unicode code points. UTF-8 byte length remains an ABI or
encoding concern and is not the language-level string length.
On the stable `cpp`, `js`, and `python` backends, a string index below zero or
at/above its code-point length returns an empty string. Combining marks are
separate code points, and an embedded NUL counts as one code point.

## 2. Rove to Rust Semantics Mapping Matrix

| Rove Construct | Canonical Language Semantic | Rust (`rust`) Mapping | Justification & Rule |
|---|---|---|---|
| **Primitives (`int`, `float`, `bool`)** | Trivially Copyable | `i64`, `f64`, `bool` (`Copy + Clone`) | Primitive stack values copy with zero overhead. |
| **String (`string`)** | Immutable Value | `String` | Literals and value boundaries produce owned strings; assignments clone payload. |
| **Array (`Array<T>`)** | Value Collection | `Vec<T>` | `var b = a` maps to `let mut b = a.clone()`. Mutation of `b` does not affect `a`. |
| **Struct (`struct Point { x, y }`)** | Plain Value Record | `#[derive(Debug, Clone, PartialEq)] struct Point` | Structs clone at Rove value boundaries; no implicit shared alias is introduced. |
| **Variable Declaration (`var x = v`)** | Scoped Mutable Variable | `let mut x = ...;` | `var` allows mutation in local scope. |
| **Constant (`const PI = 3.14`)** | Immutable Constant | local `let`; global `LazyLock<Mutex<T>>` without assignment paths | HIR verification rejects rebinding before emission. |
| **Function Parameters (`fn foo(p: T)`)** | Logical Value Parameter | `p: T` | Call sites clone non-`Copy` arguments so the caller keeps its value. |
| **Return Value (`return expr;`)** | Move Transfer | `expr` (Move transfer) | Value is moved cleanly back to the caller frame. |
| **Option / Nullable (`User?`)** | Explicit Absence or Value | `Option<T>` (`Some(...)` / `None`) | Maps directly to idiomatic `Option<T>`. |
| **Result (`Result<T, E>`)** | Sum Type Variant | generated `RoveResult<T, E>` (`Ok` / `Err`) | Preserves typed and dynamic Rove payloads without target-language inference leaks. |
| **Pattern Match (`match v { ... }`)** | Ordered case / wildcard branch | Rust `if let` / equality chain over one evaluated scrutinee | Preserves Rove case order and value binding semantics. |
| **Unsafe Memory (`addr(x)`, `peek(p)`)** | Raw Memory Address | `unsafe { *(p as *const i64) }` | Mapped strictly inside Rust `unsafe { ... }` blocks. |

## 3. Rust Code Generation Guidelines

1. **Standard Header & Preludes:**
   ```rust
   // Auto-generated by Rove (rust)
   // Target: Rust 2021 Edition (canonical typed HIR v1)
   #![allow(unused_variables, dead_code, unused_mut, non_snake_case)]
   ```
2. **Builtin Helper Functions:**
   * `print!(...)` / `println!(...)` for standard output.
   * `to_string(v)` $\to$ canonical Rove scalar display (`nan`, `inf`, lowercase Boolean).
   * `to_int(v)` $\to$ signed-i64 wrapping decimal conversion.
   * `contains(&str, &str)` $\to$ `haystack.contains(needle)`.
   * `len(&[T])` $\to$ `collection.len() as i64`; string length counts Unicode
     code points on every hosted backend.

`Task<T>`/`await`, exception, `spawn`, and channel semantics remain explicit
`E3001` capability rejections for `rust`; they are not silently approximated
with Rust futures, panics, detached threads, or partially compatible channels.
Promotion from beta requires runtime differential and Gate 8 evidence.
