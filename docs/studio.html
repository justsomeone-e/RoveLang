C++20 / native

The browser cannot invoke your local compiler. Save the editor as scratchpad.rove, then run:

rove run scratchpad.rove --target cpp

The target selector changes this command only; the preview panel never claims a native build succeeded.

Install Rove Locally

Clone the Rove source branch using the installation guide, then run the local installer. Native builds also require a C++20 toolchain.

Windows (PowerShell):
.\install.ps1
Linux & macOS (Bash):
./install.sh
