04 / RELEASE STATUS
STABLE RELEASE

v5.0.3 Daydream is current.

Nyx v5.0.3 is the current stable Daydream maintenance release. It fixes duplicate browser preview execution, separates Studio and Tour state, and preserves C++20, JavaScript, Python, Typed HIR v1, and Bundle ABI v1 contracts while keeping direct LLVM IR generation explicitly experimental.

01

Direct LLVM IR pipeline

Native scalar arithmetic, IEEE double, structured control flow, and Clang compilation without C++ hops.

02

LLVM aggregate types

Value-semantic structs, stack-owned scalar arrays, bounds verification, element copy semantics, and for-loop iteration.

03

C17 scalar backend

Portable ISO C17 emission, wrapping signed integer arithmetic, safe division aborts, and strict conformance.

04

Toolchain integration

Direct nyx build -t llvm and nyx run -t llvm compiling to native binaries via host Clang.

05

Preserved stable contracts

C++20 remains the default native path; JavaScript and Python remain stable, while WASM, Rust, React, ASM keep their declared maturity levels.

06

Canonical compiler model

All public backend paths continue through checked Typed HIR and reject unsupported constructs instead of silently falling back.

07

Native self-hosting

The reproducible Stage1 → Stage2 → Stage3 compiler path remains part of the release verification contract.

08

Release evidence

Tagged builds produce platform binaries, deterministic archives, VSIX, checksums, SBOM, and provenance after the complete workflow passes.

09

Explicit LLVM limits

Escaping arrays, nested aggregates, exceptions, tasks, closures, and complete standard-library bindings remain outside the stable LLVM contract.

LLVM and C17 are included for experimentation, not promoted to stable backends. Go, JVM, .NET, Lua, and retiring the C++ bootstrap path remain future work.
